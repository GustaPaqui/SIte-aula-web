Sobre a DevSpace

A DevSpace é uma comunidade criada para ajudar pessoas que estão começando sua jornada no desenvolvimento de software.

Aqui você encontrará dicas de estudo, conteúdos sobre prograamação e orientação para desenvolver suas primeiras aplicações.

Dicas para estudar programação

Confira algumas recomendações para organizar seus estudos

  • Pratique programação todos os dias.
  • Faça pequenos projetos para testar seus conhecimentos.
  • Leia a documentação das tecnologias utilizadas.
  • Não tenha medo de pesquisar quando encotrar um erro.
  • Revise os conteúdos estudados regularmente
  • Dividir problemas grandes em partes menores e mais fáceis de resolver.

Uma rotina de estudos

  1. Estudar o conteúdo
  2. Observar exemplos.
  3. Prática no computador.
  4. Corrigir os erros.
  5. Refazer o exercício sem consultar o exemplo.

Tecnologias para começar

Conheça algumas tecnologias importantes para quem está começando:

  • HTML - estrutura das páginas
  • CSS - aparência e apresentação
  • JavaScript - implementa elementos interativos e dinâmicos nas páginas web
A Rede de Desenvolvedores da Mozilla (MDN) é uma plataforma de aprendizagem em evolução para tecnologias da Web e o software que alimenta a Web.

Para aprofundar seus estudos, consulte a documentação da MDN.
